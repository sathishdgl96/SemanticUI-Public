# Manual pass — chat, and the unbound-report dead end

**Date:** 2026-08-17
**Driven against:** the live API and the live Snowflake account. No stubs.

## What prompted it

Three things: opening Ask or Excel on a fresh report produced "This report is
not bound to a semantic view yet, so there is nothing to ask about"; Ask was a
plain text button; and it was a one-shot question box rather than something
you could hold a conversation with and build a report from.

## Result

| # | Check | Result |
|---|---|---|
| 1 | Chat / Excel / Connect are unavailable on an unbound report | all three disabled |
| 2 | …with the reason attached, not discovered by clicking | title: "Pick a semantic view for this report first — there is no data to work with yet." |
| 3 | The control is a chat icon | button reads "💬 Chat" |
| 4 | It is enabled once a view is bound | yes |
| 5 | It opens as a dialog on a surface | 720×720, white, over the dimmed page |
| 6 | It says what it is for when empty | "Ask about this report's data in your own words…" |

| 10 | Page errors | none |

## What could NOT be verified here, and why

**The answer path.** This account is a trial, and `SNOWFLAKE.CORTEX.COMPLETE`
is not available on trials — every question comes back:

> Snowflake Cortex is not available on this account: AI function COMPLETE is
> not available for trial accounts.

So the browser pass exercised the panel, the icon, the layout, the error path
and the accumulation of turns, but **not** a real answer, and **not** a real
follow-up resolved against history. Those are covered by tests instead:

- `frontend/src/ask/ChatPanel.test.tsx` asserts the exact request body of a
  second turn — `history: [{question, answer}]` — and that it contains neither
  the rows nor the values from the first answer.
- `backend/tests/test_ask_routes.py` asserts the history reaches the prompt.
- `backend/tests/test_cortex_prompt.py` asserts it is trimmed to the last six
  turns, cannot close the question block, and carries no rows.

That is a real gap: nobody has seen the model resolve "now split that by
nation" against the turn before it. It stays gated behind
`SEMANTICUI_IT_CORTEX=1` on an account where Cortex runs.

## Design notes

**Only answered turns become history.** An unanswered question would tell the
model a thing was asked and leave it guessing what came of it.

**What travels back is the question and the model's own explanation** — never
the rows. Keeping data out of the prompt is what makes this safe to point at a
governed model, and a conversation is the place it would be easiest to lose by
accident. There is a test on each side asserting it.

**Six turns.** A chat that carries its whole history grows the prompt without
bound; the recent turns are what a follow-up actually refers to.

**The audit is one click away, not gone.** The spec and the SQL sit behind a
"How this was answered" disclosure in every answer bubble, rather than being
the loudest thing in it.
